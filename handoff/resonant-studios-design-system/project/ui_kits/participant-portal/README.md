# ui_kits/participant-portal — Resonant Studios portal

The logged-in participant portal. Calm, clear, outcome-focused. Not a dashboard — a simple surface for: your next session, your journey progress, your song project, and your messages.

## Components

- `PortalShell.jsx` — sidebar + top bar shell
- `Sidebar.jsx` — navigation with plum active state
- `NextSession.jsx` — primary "next session" card
- `GoalsCard.jsx` — plan goals + progress
- `SongProject.jsx` — current song with inline player + takes
- `UpcomingList.jsx` — compact upcoming sessions list
- `MessagesPanel.jsx` — conversation with facilitator

Canvas: 1280×900.
