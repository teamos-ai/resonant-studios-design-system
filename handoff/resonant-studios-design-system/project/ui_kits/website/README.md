# ui_kits/website — Resonant Studios marketing site

A warm, editorial marketing site. Sits around `index.html` which assembles the hero, explainer, journey, NDIS info, stories, and CTA sections.

## Components

- `Nav.jsx` — top nav with copper underline + book CTA
- `Hero.jsx` — editorial hero with display type and studio photograph plate
- `HowItWorks.jsx` — three-step explainer cards
- `Journey.jsx` — 8-session journey rail
- `NdisBlock.jsx` — plan-managed / self-managed info card
- `Story.jsx` — participant story pull-quote with audio player
- `CtaBand.jsx` — closing "book an intro call" band
- `Footer.jsx` — footer with acknowledgement of country

Canvas width: 1200px content, full-bleed background. Preview at 1280×900 above the fold.
