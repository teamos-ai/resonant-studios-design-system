## House rules (summary — see README for detail)

- Warm paper bg, never pure white. Charcoal ink `#2B2722`, never pure black.
- Plum `#6B4B5E` primary. Sage `#7A8F82` secondary. Copper `#B07848` as spice (never CTA).
- **Two faces only.** DM Serif Display for headings (with italic for emphasis & song titles). Manrope for everything else — body, UI, numerals, codes. No other families.
- Paper grain overlay on body at 5-8%.
- Rounded corners everywhere. 14px cards, 10px inputs/buttons, pill tags.
- Soft warm-tinted shadows. No grey/black shadows.
- Out-expo easing, 140/220/420ms. No bounces.
- Lucide icons, 1.5px stroke, currentColor.
- No emoji. Sentence case. Second person "you". Calm, clear, outcome-focused.
- Tone: structured support service. Not clinical. Not producer-speak.
